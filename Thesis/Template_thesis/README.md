# Thesis Template

Compile `template_thesis.tex` with XeLaTeX + BibTeX + XeLaTeX + XeLaTeX.

The template entry file is `template_thesis.tex`. The class file is `hitbook-en.cls`.

Before uploading as a template, keep the files in the root of this folder and the example subfolders `sections/`, `back/`, `figures/`, and `reference.bib`.

The original class-file backup is stored outside this folder in `../cls_backup_20260527/`. This template folder is intended to be uploadable as a clean template.
