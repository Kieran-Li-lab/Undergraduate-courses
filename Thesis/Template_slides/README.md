# HIT-SPBU Beamer Template

Compile with XeLaTeX.

Minimum upload unit for Overleaf:

- `template.tex`
- `beamerthemehitspbu.sty`
- `hit-template-assets/`

The file `beamerthemehitspbu.backup-20260526.sty` is a backup copy of the theme at the time this template folder was created. It is not required for compilation.

Use `\begin{frame}[noframenumbering]{...}` for backup/question slides that should keep the template style but not affect the total page count.
